# Changelog

All notable changes to this project will be documented in this file.
Format follows [Keep a Changelog](https://keepachangelog.com/).

## [1.2.0] - 2026-05-11

### Added
- AI/LLM semantic enhancement layer (Qwen + GPT dual-provider)
- A/B testing framework for model comparison
- IB/Protocol information flexibility (FULL/PARTIAL/BLIND modes)
- PDF export with Chinese font support (FangSong + Times New Roman)
- Word (.docx) export with formal report structure
- JSON structured export (full + minimal modes)
- Streamlit web dashboard
- Visualization module (8 chart types, 3 themes)
- Drug causality audit with quantitative confounding scoring

## [1.1.0] - 2026-05-10

### Added
- CTCAE v5.0 grading engine with Hy's Law screening
- AE quality 10-dimension audit
- Cross-domain auditing (CM-AE, MH-CM, LB-AE)
- Statistical toolbox (OR, Chi-square, trajectories)
- Subject-level database builder
- 22-section report generator

## [1.0.0] - 2026-05-09

### Added
- Initial framework: EDC parser, pipeline orchestrator
- Basic audit rule engine
- Excel export
